Ferramenta de Migração

Elo7/Nuvemshop

Cole o código-fonte das páginas da sua lista de produtos da Elo7 e gere automaticamente um CSV pronto para importar na Nuvemshop.

HTML da Elo7 → Extração automática → CSV formatado → Nuvemshop
1
Cole o HTML das páginas de produtos
Até 3 páginas — repita o processo para cada uma
Como obter o código-fonte:
Acesse sua lista de produtos da Elo7 → Ctrl+U (abre o fonte) → Ctrl+A para selecionar tudo → Ctrl+C para copiar → cole aqui.
Para a página 2, adicione &pageNum=2 no endereço antes de repetir.
2
Valores padrão
Aplicados em todos os produtos — você edita depois na Nuvemshop
Dica: Produtos Esgotados serão importados com Exibir na loja = NAO automaticamente.
Produtos Sob encomenda serão importados com estoque - (infinito).
Campos como Descrição, Categorias e Tags ficam em branco — complete depois na Nuvemshop.
